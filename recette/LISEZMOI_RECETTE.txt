RECETTE AITE HOUSE — contenu et régénération
=============================================
- AITE_HOUSE_cahier_de_recette.xlsx : outil de travail (4 onglets :
  Synthèse, Cas de test, Anomalies, Mode d'emploi). 139 cas, statuts en
  listes déroulantes, compteurs automatiques par statut et par domaine.
- AITE_HOUSE_plan_de_recette.pdf : plan de recette + procès-verbal
  signable (14 pages).

Modifier / compléter les scénarios :
  1. Éditer cas_de_test.py (liste CAS : id, domaine, priorité, pré-requis,
     scénario, étapes, résultat attendu). Priorité 1=critique, 2=majeur,
     3=mineur. Domaines A..P définis dans DOMAINES.
  2. pip install weasyprint --break-system-packages   (si absent)
  3. python3 build_xlsx.py        (écrit le classeur à côté du script ; RECETTE_OUT=<dossier> pour ailleurs)
     ouvrir/enregistrer dans LibreOffice ou Excel pour recalculer les formules
     (ou : soffice --headless --convert-to xlsx)
     python3 build_plan.py        (PDF ; logo_aite.jpg à côté du script)
Les deux livrables se régénèrent à l'identique depuis la même source : le
classeur et le PDF restent toujours cohérents.
