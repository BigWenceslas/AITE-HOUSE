# AITE — Direction (vue consolidée)

Cockpit du gérant en six onglets : Vue d'ensemble, Ventes (POS), Crédit
clients, Stock, Achats, À traiter. Le backend ORCHESTRE les moteurs des
quatre tableaux de bord spécialisés (mêmes chiffres garantis) et
n'ajoute que la couche transversale : cash à risque, position nette
clients/fournisseurs, série d'encours, échéancier, actions du gérant.

Filtres : période (6 raccourcis + plage Du/au), caisse, tranche
horaire, jours (multi). Caisse / heure / jours s'appliquent aux données
de vente ; les cartes « photo » (encours, dettes, stock) sont des
instantanés. Menu « Direction » réservé aux responsables Point de
Vente. Chaque carte de pôle et chaque ligne « À traiter » ouvre le
tableau de bord spécialisé.

Installation : dossier dans les addons → Apps → Mettre à jour la
liste → installer « AITE — Direction (vue consolidée) » → redémarrer
Odoo → Ctrl+Shift+R.
